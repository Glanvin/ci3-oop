# CodeIgniter 3 - OOP Interactive Testing Ground

> **Note on Framework Version:** CodeIgniter 3 is a legacy framework. For modern production web applications, it is strongly recommended to use **[CodeIgniter 4](https://codeigniter.com/)** or newer. This repository specifically uses CodeIgniter 3 to align with course requirements and academic activities.

---

## About This Project
This repository serves as a synchronized workspace for an **Object-Oriented Programming (OOP)** course. It is used to:

* Sync progress across school lab computers and personal devices.
* Share code, reference material, and OOP experiments with classmates.
* Complete course-specific class activities and assignments based on the CodeIgniter 3 architecture.

---

## About CodeIgniter
CodeIgniter is an Application Development Framework a toolkit for building websites using PHP. Its goal is to accelerate project development by providing a rich set of libraries for commonly needed tasks, alongside a simple interface and logical structure to access them. CodeIgniter allows you to focus creatively on your project by minimizing the amount of code required for any given task.

## Getting Started

### Requirements
* **PHP:** 5.6 or newer (PHP 7+ recommended)
* **Web Server:** Apache, Nginx, or local server environments (e.g., XAMPP, WAMP, Laragon)
* **Database:** MySQL / MariaDB (if required for specific activities)

### Quick Setup

#### Option A: Using Git CLI
1. Open your terminal or command prompt and run:
   ```bash
   git clone https://github.com/Glanvin/ci3-playground
   cd your-repo-name

#### Option B:Using GitHub Desktop (Recommended for School Computers)
1. Open **GitHub Desktop**.
2. Go to **File** > **Clone Repository...** (or press `Ctrl + Shift + O` / `Cmd + Shift + O`).
3. Select the **URL** tab.
4. Paste the repository URL: `https://github.com/your-username/your-repo-name.git`
5. Choose your local directory (e.g., inside your XAMPP `htdocs` or local server folder) and click **Clone**.
